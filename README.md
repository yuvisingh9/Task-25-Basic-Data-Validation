# Task 25: Basic Data Validation

## Project Overview
This project demonstrates the use of Excel data validation to improve employee data-entry accuracy and spreadsheet quality.

## Objectives
- Improve spreadsheet data quality.
- Restrict invalid data entries.
- Create dropdown lists for consistent data entry.
- Detect duplicate employee IDs and email addresses.

## Tools Used
- Microsoft Excel
- Data Validation
- Dropdown Lists
- Conditional Formatting
- Excel Formulas

## Workbook Contents
1. **Start Here** – Instructions and guidelines.
2. **Employee Data** – Employee data-entry template with sample records.
3. **Lists** – Department, employment type, and status dropdown options.
4. **Validation Summary** – Automatic data quality statistics.

## Key Features
- Department dropdowns.
- Employment type dropdowns.
- Employee status dropdowns.
- Email format validation.
- Unique employee ID validation.
- Salary and joining date restrictions.
- Duplicate detection.
- Automatic VALID/CHECK status.

## Deliverables
- Validated Excel template.
- Five synthetic sample employee records.
- Dropdown lists and validation rules.
- Data quality summary.

## Conclusion
This project demonstrates how spreadsheet validation can reduce data-entry errors and improve the consistency and reliability of employee records.
